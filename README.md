# SQL Sales Data Analysis Project

## Project Overview
This project demonstrates SQL-based data querying and reporting using customer and order sales data.

## Tools Used
- SQL
- SQLite Online
- GitHub

## Concepts Used
- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- Foreign Key Relationship

## Analysis Performed
- Total sales calculation
- Customer-wise spending analysis
- City-wise sales analysis
- High-value order filtering
- Average order value calculation
- Total order count

## Database Tables

### Customers Table
Contains customer details such as customer ID, name, and city.

### Orders Table
Contains order details such as order ID, customer ID, product, and amount.

## Objective
To analyze sales data using SQL queries and generate meaningful business insights from relational datasets.
